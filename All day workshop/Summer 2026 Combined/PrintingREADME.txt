1. To add in the AI slides, do the following:

	a. Print out the AI slides in notes format (3 to a page) to PDF.
	b. Manually change the page numbers on the PDF pages to be the chapter title page from the main PDF + 1. 
	c. Split the main PDF file by chapter headers using the split function and selecting the option in the drop down menu.
	d. In the file associated with the AI chapter, split that file again 1 page in each file.
	e. Change the page number in the second page from the AI chapter to 1 page + the last page number from the AI slides handout.
	f. Combine the three files for the AI chapter: first page, AI slides handout, and second page.
	g. Create one large combined file with all chapters plus the combined AI chapter.
	h. NOTE: DO NOT delete the separate chapter files yet.

2. Print each chapter separately, the number of copies needed for the workshop.

3. For the Data Visualization chapter, make sure to flatten that file by going to Tools > More Tools > Use Print Production > Flattener Preview and change the resolution to medium. Apply to all pages in the chapter. After it is flattened, then print all of the needed copies.

4. After all chapters are printed, delete the subset files.
